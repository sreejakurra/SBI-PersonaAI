# SBI PersonaAI

## AI Relationship Manager for Intelligent Customer Acquisition

### Overview
SBI PersonaAI is an Agentic AI-powered Relationship Manager that transforms traditional banking onboarding into a personalized conversational experience.

### Features
- Adaptive AI Conversations
- Financial Identity Profile
- Personalized Product Recommendations
- Guided Digital Onboarding
- Explainable AI

### Tech Stack
- React.js
- Google Gemini API (Planned)
- FastAPI (Planned)
- PostgreSQL (Planned)


### Status
Prototype submitted for SBI Hackathon 2026.
